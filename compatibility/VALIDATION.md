# 验证记录 — 2026-10-21

执行环境为 Debian 13、Wine 10.0、PowerShell 7.4.6。Cascadeur 安装文件均直接来自
官网 `cascadeur.com/storage/builds/`，程序日志确认版本 2026.1.3 与 2026.2.3。

| 检查 | 结果 |
| --- | --- |
| 2026.1.3 最小绑定加载，无 QtGui/QtQuick Python 模块 | 通过 |
| 原事件钩子精确加载工具包；旧 commands_rule 发现 Scene Clean | 通过 |
| 实际加载 Cascy.casc，读取 289 个对象、66 根骨骼及导入/导出读取适配器 | 通过 |
| 有真实 QML 窗口时重复枚举窗口 1000 次 | 通过 |
| Import/Export 菜单安装、重复安装、排队回调、销毁后重建 | 通过 |
| 消息、确认、模型选择、导出策略、进度窗口生命周期 | 通过 |
| 新旧宿主能力预检；新版选择 native 且不覆盖宿主绑定 | 通过 |
| 预览无写入、安装幂等、绑定冲突保护、修改文件恢复保护 | 通过 |
| 原文件精确恢复、新增目录恢复、中途失败完整回滚 | 通过 |
| 包内全部文件大小与 SHA256、Python/PowerShell 语法 | 通过 |
| 现代窗口实现与原始 v1.0 发布包逐字节比较 | 一致 |

安装事务测试读取真实 Windows PE 文件和导出符号，在 Linux PowerShell 中仅
替换 Windows 路径解析和原生 VERSIONINFO 访问。没有执行原生 Windows
PowerShell 5.1 或 UAC 提权安装，不能将这些事务测试描述为 Windows 实机安装测试。

宿主窗口测试在 Cascadeur 的命令模式中创建独立 QML 菜单夹具；完整 GUI 在
当前 Wine 环境停留于启动阶段，未完成真实交互菜单和文件选择器的端到端验证。
2026.2.3 的窗口烟测在 Wine 中出现原生 Python 崩溃，使用原始现代窗口实现
也出现该结果，因此未将新版窗口运行回归标记为通过。最终包为新版逐字节保留
原窗口实现，只为旧版加载独立的 `legacy_dialogs.py`。

没有用户具体 PMX/VMD 工程，未验证这些工程的整段动作导入、导出和 Scene Clean。
本次结论是安装兼容及上述旧版宿主能力测试通过，不是全部模型/动画结果的保证。
