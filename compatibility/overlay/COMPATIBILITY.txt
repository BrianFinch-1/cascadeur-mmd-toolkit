Cascadeur MMD toolkit 1.0 — 2026.1.3 compatibility revision 1

安装方式保持不变：关闭 Cascadeur，完整解压 ZIP，双击 Install.cmd，输入
直接包含 cascadeur.exe 的目录。安装器显示 legacy / native 宿主模式。
需要恢复时，关闭 Cascadeur，运行 Restore.cmd 并输入安装时的备份目录。

legacy：官网 Windows x64 Cascadeur 2026.1.3 / CPython 3.11 / Qt 6.5.3。
提供官方 PySide6-Essentials 与 Shiboken6 6.5.3 的最小未修改子集，仅包含
QtCore、QtNetwork、QtQml 绑定；另附 CPython 3.11 stable-ABI 转发 DLL。
旧版 Qt 缺少完整 GUI 绑定所需的导出符号，因此不安装 QtGui/QtQuick 绑定。
菜单通过宿主 QML 引擎直接连接 Python 回调，不依赖 2026.2 的脚本服务器，
也不安装 D3D11 代理。Scene Clean 同时支持新旧命令注册名称。

native：保留 2026.2+ 原有 PySide6、原生代理和脚本回调路径。修正了把
Qt 内联 topLevelWindows 当作必须 DLL 导出的检查，保留实际 allWindows 导出检查。

不替换 Cascadeur 的 Qt DLL、Qt 插件、QML 模块或 python311.dll。
运行时文件参与原有 SHA256 校验、备份、写入失败回滚和恢复事务。
旧版已存在但不匹配的 Python 绑定会在写入前被拒绝。
本包仍为 Windows x64 安装包，不是 Linux 移植版。

验证范围：官网 Windows 2026.1.3 在 Linux/Wine 的命令模式中加载绑定、
读取 Cascy 示例场景、创建真实 QML 窗口并验证菜单/回调和窗口生命周期。
命令模式测试创建独立菜单夹具，不代表完整交互界面的端到端测试。
安装事务另在 Linux PowerShell 中验证，测试仅适配了 Windows 路径和
PE 版本信息访问；没有完成原生 Windows PowerShell 5.1/UAC 的实机测试。
尚无用户具体 PMX/VMD 工程的完整导入导出结果，建议先用工程副本试用。

2026.2.3 的窗口烟测在 Wine 中出现原生崩溃，未标记为通过；使用原始现代
窗口实现的测试也出现该结果。最终包从上游逐字节保留现代窗口实现，仅旧版
加载独立兼容窗口模块。详细结果见仓库 compatibility/VALIDATION.md。
