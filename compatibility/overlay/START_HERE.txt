cascadeur MMD toolkit 1.0

安装
1. 先将整个压缩包解压到普通文件夹，不要直接在压缩包内运行安装器。
2. 关闭准备安装插件的那个 Cascadeur。
3. 双击 Install.cmd。
4. 在窗口中粘贴 Cascadeur 安装根目录，按 Enter。例如 C:\Program Files\Cascadeur；应能在该目录中找到 cascadeur.exe。不是项目工程目录，也不是 resources 子目录。
5. 如 Windows 请求管理员权限，请检查安装路径后允许。等待“安装成功 / Installation completed”。安装器会自动检查 Windows x64、CPython 3.11、Qt 和官方脚本接口能力；不会按 Cascadeur 版本号或可执行文件 hash 放行。
6. 记下窗口显示的备份目录，然后启动新的 Cascadeur 进程。更完整的操作步骤请看“使用教程 User Guide.pdf”。

失败或取消：窗口会保留，按任意键才关闭。失败会显示原因；如已开始写入，会自动回滚并记录结果。若显示 rollback incomplete，请保留窗口和备份，不要启动 Cascadeur，先解决占用/权限后用 Restore.cmd 恢复。
恢复：关闭对应的 Cascadeur，双击 Restore.cmd，粘贴原安装窗口显示的完整备份目录，按 Enter。默认备份位于 %LOCALAPPDATA%\cascadeur MMD toolkit\backups。若安装后这些文件又被修改，恢复器会拒绝覆盖，并提示具体文件。
安装器会保留无关插件；若已有无法识别的 D3D11.dll，会拒绝覆盖并提示冲突。

Install
1. Extract the entire archive to a normal folder before running anything.
2. Close Cascadeur from the installation you want to update.
3. Double-click Install.cmd.
4. Paste the Cascadeur installation root and press Enter, for example C:\Program Files\Cascadeur. It contains cascadeur.exe. Do not choose a project directory or the resources subdirectory.
5. Allow Windows administrator access if requested after checking the path. Wait for “Installation completed”. The installer checks Windows x64, CPython 3.11, Qt and official scripting capabilities. It does not accept or reject by Cascadeur version number or executable hash.
6. Keep the displayed backup directory, then start a new Cascadeur process. Read 使用教程 User Guide.pdf for the full guide.

Failure or cancellation: the console stays open until you press a key. Failures display a reason. A failed transaction automatically rolls back its writes and records the result. If rollback is incomplete, keep the message and backup, resolve locks/permissions, then run Restore.cmd before starting Cascadeur.
Restore: close the relevant Cascadeur, double-click Restore.cmd, paste the full backup directory displayed during installation, and press Enter. Backups default to %LOCALAPPDATA%\cascadeur MMD toolkit\backups. If installed files have subsequently changed, restore refuses to overwrite them and identifies the file.
Unrelated plugins are preserved. An unrecognized existing D3D11.dll causes a conflict error rather than being overwritten.


2026.1.3 compatibility revision 1
=============================
支持官网 Windows x64 Cascadeur 2026.1.3（Qt 6.5.3 / CPython 3.11）。
安装器自动选择宿主模式。旧版补齐匹配的 QtCore/QtNetwork/QtQml 绑定、
Shiboken 和 CPython stable-ABI 转发器，使用宿主 QML 引擎直接处理菜单回调。
不替换宿主 Qt DLL，不安装 QtGui/QtQuick Python 绑定，也不安装 D3D11 代理。
新版保持原有安装路径和绑定。安装器拒绝覆盖旧版中未知或残缺的绑定。
所有新增运行文件均记录在原有备份/恢复事务中；恢复前先关闭 Cascadeur。
本补丁仍为 Windows 发布包，不是 Linux 版。见 COMPATIBILITY.txt。

The installer selects the host profile automatically. On the legacy host it
adds only the tested QtCore/QtNetwork/QtQml bindings, Shiboken and CPython ABI
forwarder, and uses direct QML menu callbacks. Host Qt DLLs are preserved.
Modern hosts keep their existing bindings and native callback path. Added
files participate in the original backup/restore transaction. Windows only.
